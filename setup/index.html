Setup

Pre-tournament preparation only: create the event, import the roster, build groups, then move to Ring Assignment or Head Table when tournament time starts.

Step 1

Event lifecycle

Create a new tournament event, activate an existing one, or reset the active event before competition starts.

Step 2

Import roster

Load the competitor CSV into the active event database. Use a local file path on the server machine.

  • The server import endpoint writes into the selected event DB.
  • Import before building groups.
Step 3

Build groups

After the roster is imported, open the group builder to generate competition groups.

Assign rings

Once groups are ready, move to Ring Assignment. This stays separate from tournament-time monitoring.
